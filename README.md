# 🧠 Quiz App (React)

Une **application de quiz interactive** construite avec **React.js** pour tester les connaissances à choix multiples dans le navigateur.

---

## 📌 Description

Ce projet est une **application de quiz dynamique** développée avec **React.js**.  
Elle permet aux utilisateurs de répondre à des questions, de suivre leur progression et d’afficher leur score à la fin du quiz.

---

## 🛠️ Technologies utilisées

- **React.js** – Framework JavaScript pour l’interface
- **CSS3** – Styles visuels
- **HTML5** – Structure de base
